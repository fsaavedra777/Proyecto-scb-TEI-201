# Diseño 3D
Esta carpeta contiene los archivos CAD
del sistema SCB desarrollados en Fusion 360.
### Contenido
- Modelo 3D del ensamblaje.
- Piezas individuales.
- Planos técnicos.
- Renders del diseño.
- Guía para hacer el montaje con las piezas
### Fabricación
Las piezas fueron diseñadas para
fabricación mediante impresión 3D.
Se utilizaron PLA y TPU.
