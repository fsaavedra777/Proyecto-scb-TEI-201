# Proyecto SCB
## Sistema de Clasificación de Basura

### 1. Descripción
SCB es un sistema automatizado que permite
clasificar residuos mediante sensores,
pesarlos y depositarlos en el contenedor
correspondiente.

### 2. Integrantes
- Facundo Saavedra
- Matías Jara
- Martín Olivares

### 3. Componentes
- Arduino UNO
- Sensor ultrasónico HC-SR04
- Celda de carga y HX711
- Sensor inductivo LJ12A3
- Sensor capacitivo LJC18A3
- Sensor FSR-402
- Servomotores SG90/MG90S

### 4. Funcionamiento
1. Recepción del residuo.
2. Detección mediante sensor ultrasónico.
3. Medición de masa.
4. Identificación del material.
5. Agarre mediante pinza.
6. Depósito en el contenedor.

### 6. Instrucciones de uso
1. Conectar el Arduino UNO.
2. Abrir el código en Arduino IDE.
3. Instalar las bibliotecas necesarias.
4. Cargar el programa al Arduino.
5. Conectar los sensores y servomotores.
