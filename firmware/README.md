# Firmware

Esta carpeta contiene el código fuente
utilizado para controlar el sistema SCB
mediante el Arduino UNO.

### Contenido
- SCB_clasificador.ino: programa principal del sistema.

### Funciones principales
- Lectura de sensores.
- Detección de residuos.
- Medición de masa.
- Identificación de materiales.
- Control de servomotores.
- Ejecución de la máquina de estados.
