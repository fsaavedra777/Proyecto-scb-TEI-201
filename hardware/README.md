# Hardware

Esta carpeta contiene la documentación
del circuito electrónico y los componentes
utilizados en el proyecto SCB.

### Contenido
- Esquemático eléctrico.
- Lista de materiales (BOM).
- Fotografías del montaje.

### Componentes principales
- Arduino UNO.
- HC-SR04.
- HX711 y celda de carga.
- Sensores inductivo y capacitivo.
- FSR-402.
- Servomotores (MG-996r y sg-90)
